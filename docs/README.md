# `docs/` — Documentation Assets

This directory contains documentation assets and templates for the Ironworks project.

## Files

| File | Purpose |
|------|---------|
| `banner.svg` | GitHub README banner graphic displayed at the top of the main README |
| `layers.svg` | Layer architecture diagram showing the 7-layer skill organization |
| `CLAUDE-GLOBAL.md` | Drop-in global instructions for `~/.claude/CLAUDE.md` — configures Claude Code with Ironworks defaults across all projects |
| `CLAUDE-PROJECT-TEMPLATE.md` | Template for project-level `CLAUDE.md` — generated by `/iron:init` and customized per project |
