# Security Policy

## Scope

This policy covers the Ironworks skill definitions and plugin infrastructure — not the code that skills help you generate. The skills themselves are instruction sets (Markdown files) that guide AI coding agents; they do not execute code directly.

## Reporting a Vulnerability

If you discover a security issue in the Ironworks skills or plugin configuration, please report it:

- **Email:** rahulhulsureofficial@gmail.com
- **GitHub:** Open a [security issue](https://github.com/RahulHulsure/-Ironworks/issues) with the `security` label

Please include:
- Which skill or file is affected
- Description of the vulnerability
- Steps to reproduce (if applicable)

We aim to respond within 7 days.
